# VSA Trading Assistant 📈🤖

VSA Trading Assistant — это торговый LLM-агент для помощи трейдерам на рынке Форекс (в частности EURUSD). Бот анализирует рыночные графики на основе методологий **VSA (Volume Spread Analysis)** и **VPA (Volume Price Analysis)**.

Бот может работать как автономно в фоне (опрашивая рынок каждые 15 минут), так и через интерактивный веб-интерфейс на базе Streamlit, где трейдер может общаться с ботом в формате чата, уточняя детали анализа.

## 🌟 Ключевые особенности архитектуры

1. **Фьючерсные данные и базис:** На Форексе нет централизованного объёма. Скрипт берёт точные OHLC и Volume из чикагского фьючерса `6E=F` (CME). Свечи фьючерса используются для LLM и генерации сигналов, а для реальной торговли цены автоматически транслируются в цены спота через расчет медианного базиса (разницы) между фьючерсом и спотом.
2. **Локальный расчет VSA-признаков:** Нейросеть не считает сырые данные. В `core.py` заранее вычисляются критически важные метрики для VSA по 60 последним закрытым свечам: `rel_volume` (относительный объем к MA20), `spread` (размер свечи), `close_pos` (положение закрытия 0..1), `has_gap` (наличие гэпа) и торговая сессия (Asia/London/Overlap/NY).
3. **Фильтрация незакрытых свечей и stale-гейт:** Несформировавшаяся текущая свеча отбрасывается. Если рынок закрыт или пауза превышает 20 минут, бот сигнализирует о неактуальности данных (`is_stale`) и пропускает вызов LLM.
4. **Строгая валидация сигналов (Python, не LLM):** LLM предлагает только уровни (entry, stop, take) через JSON. Python-функция `calculate_position_size()` жестко проверяет логику: стоп не может быть меньше 5 пипсов, цена входа не может отклоняться от рынка более чем на 50 пипсов, объем ограничен сверху. При ошибке LLM-сигнал отклоняется с текстовой причиной. 
5. **Prompt Caching (Anthropic/OpenRouter):** Системный промпт разделён на логические блоки с `cache_control: ephemeral` для кэширования огромного контекста (конспекта VSA). Это снижает стоимость API и ускоряет ответы.
6. **SQLite Логирование (`signals.sqlite`):** Все сгенерированные сигналы, количество токенов, стоимость вызова (cost) и хэш состояния рынка автоматически сохраняются в базу данных.
7. **Оптимизированная история чата:** Для сохранения кэша и снижения расходов старые сообщения сжимаются до текстового вида, а полный JSON 60 свечей вкладывается только в текущий запрос.
8. **Replay Mode (Исторический прогон):** Скрипт `replay.py` позволяет прогнать торговую логику бота за последние 60 дней истории (sliding window).

## 📂 Структура проекта

* `app.py` — Интерактивный веб-интерфейс на базе **Streamlit**.
* `bot.py` — Консольный демон для запуска на сервере/VPS с фоновым планировщиком.
* `core.py` — Ядро бизнес-логики: получение котировок, расчет базиса, VSA-фич, расчет позиции, валидация сигналов, логирование в SQLite и API вызовы.
* `replay.py` — Скрипт для прогонов исторических данных (создает симуляцию движения рынка с записью ответов в БД).
* `tests/test_core.py` — Pytest-сьют (модульное и регрессионное тестирование).
* `tools/pdf_to_md.py` — Вспомогательная утилита конвертации книг PDF в Markdown.
* `VSA_REFERENCE.md` — Структурированный референс по VSA/VPA (~35k токенов). Загружается в системный промпт как база знаний.
* `requirements.txt` — Фиксированные зависимости проекта.
* `.env.example` — Шаблон конфигурации переменных окружения.

## 🚀 Установка и запуск

1. Склонируйте репозиторий / откройте папку проекта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и укажите ваш API-ключ OpenRouter:
   ```bash
   cp .env.example .env
   ```
   Или задайте параметры вручную в `.env`:
   ```env
   OPENROUTER_API_KEY=ваш_ключ_здесь
   MODEL=anthropic/claude-3.5-sonnet
   ```
4. **Тестирование системы:**
   ```bash
   pytest tests/test_core.py
   ```
5. **Запуск веб-интерфейса:**
   ```bash
   streamlit run app.py
   ```
6. **Запуск консольного демона:**
   ```bash
   python bot.py
   ```
7. **Запуск Replay Mode:**
   ```bash
   python replay.py
   ```

## 🧠 Как это работает

1. **Сбор данных:** `core.get_market_data()` скачивает свечи `6E=F`, отбрасывает текущую незакрытую свечу, проверяет на актуальность (`is_stale`), считает VSA-фичи и медианный базис к споту.
2. **Запрос к LLM:** `core.call_llm()` отправляет структурированные блоки промпта + оптимизированную историю + JSON со 60 закрытыми свечами в OpenRouter.
3. **Парсинг ответа:** `core.format_response()` извлекает JSON-блок с сигналом (с поддержкой fallback-парсинга).
4. **Валидация и расчет:** Python применяет фильтры и рассчитывает объемы в лотах на основе риска, размера депозита и дистанции стопа с учетом конвертации базиса в цены спота MT5.
5. **Логирование:** Данные сохраняются в `signals.sqlite`.
