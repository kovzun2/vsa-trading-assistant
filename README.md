# VSA Trading Assistant 📈🤖

**VSA Trading Assistant** — это профессиональный торговый LLM-агент для анализа рынка Форекс (в частности EUR/USD) на основе методологий **VSA (Volume Spread Analysis)** и **VPA (Volume Price Analysis)**.

Бот объединяет точность объемов чикагского фьючерса CME, строгие алгоритмы математического риск-менеджмента на Python, интерактивные графики Plotly, прямой авто-синк с терминалом **MetaTrader 5** и интеллектуальный режим **живого мониторинга сессии в реальном времени**.

---

## 🌟 Ключевые особенности и архитектура

1. **Фьючерсные данные CME (`6E=F`) и расчет базиса:**
   На спот-форексе нет централизованного объёма. Скрипт запрашивает точные OHLC и Volume из фьючерса `6E=F` (CME). Свечи фьючерса передаются в LLM и используются для генерации сигналов, а цены автоматически конвертируются в спотовые ценники MT5 через скользящий медианный базис (`fut_close - spot_close`).
2. **Локальный расчет VSA-признаков (Python):**
   Нейросеть получает готовую математику VSA по 60 закрытым 15-минутным свечам (~15 часов контекста): `rel_volume` (относительный объем к SMA20), `spread` (размер бара), `close_pos` (положение закрытия 0..1), `has_gap` (наличие разрывов) и торговую сессию (Asia/London/Overlap/NY).
3. **Интерактивный VSA-график (Plotly):**
   В веб-интерфейсе выводится свечной график с цветовой подсветкой VSA-объемов:
   - 🟣 **Фиолетовый** — *Ultra High Volume* (кульминация объема/всплеск интереса `rel_vol ≥ 1.5`).
   - 🟡 **Жёлтый** — *Low Volume / No Supply* (`rel_vol ≤ 0.4`).
   - 🔵 **Голубой** — обычный объем.  
   При наличии сигнала на график автоматически наносятся пунктирные уровни: **ENTRY**, **STOP-LOSS** и **TAKE-PROFIT**.
4. **Живой 15м мониторинг и движок IF-THEN гипотез:**
   В режиме авто-мониторинга бот опрашивает закрытие каждой 15-минутной свечи, проверяет предыдущие гипотезы и формирует сценарные условия на следующий бар (*«Если следующая свеча закроется бычьей с объемом > 1.2, ТО...»*), выдавая ордер только при полном согласии паттерна. В веб-интерфейсе страница автоматически обновляется каждые 60 секунд (`streamlit-autorefresh`), пока включён тумблер мониторинга; консольный демон `bot.py` имеет собственный планировщик с дедупликацией уже проанализированных свечей.
5. **Прямая синхронизация с MetaTrader 5:**
   В один клик подтягивает реальный баланс счета, эквити, валюту и плечо из запущенного терминала MT5, автоматически подставляя реальный депозит в формулу расчета риска.
6. **Торговый журнал & Статистика Winrate:**
   Встроена база данных `signals.sqlite` с дашбордом статистики: вычисление **Winrate %**, количества успешных (TP) и убыточных (SL) сделок. Исходы pending-сигналов отслеживаются **автоматически** по касанию TP/SL новыми свечами (сделка считается открытой после касания уровня входа), доступна и ручная правка результатов.
7. **Строгая валидация сигналов и защита пятничного закрытия:**
   Расчет позиций выполняется на Python (не в LLM): стоп $\ge$ 5 пипсов, вход не далее 50 пипсов от рынка, кап по лотам (до 100 лотов). Сигналы перед выходными автоматически блокируются во избежание гепов.
8. **Prompt Caching и калькуляция расходов:**
   Конспект книг VSA (~35k токенов) кэшируется (`cache_control: ephemeral`). В интерфейсе выводится стоимость каждого запроса и накопительный расход по БД.  
   > ⚠️ **Важно:** механизм Prompt Caching со скидкой ~90% поддерживается только моделями **Anthropic Claude** (например, `anthropic/claude-3.5-sonnet`). Для остальных моделей (включая дефолтную `z-ai/glm-5.2`) провайдер просто игнорирует этот параметр — скидки не будет.

## 📂 Структура проекта

* `app.py` — Полноценный веб-интерфейс на **Streamlit** с Plotly-графиком, авто-мониторингом, синхронизацией MT5 и Торговым журналом Winrate.
* `bot.py` — Фоновый консольный демон для сервера/VPS с точным планировщиком тайминга.
* `core.py` — Ядро бизнес-логики: получение котировок, VSA-фич, расчет базиса, валидация позиций, генерация Plotly-графика, интеграция с MT5, SQLite-логирование и вызовы OpenRouter.
* `replay.py` — Скрипт бэктеста для прогона исторического слайдинг-окна свечей.
* `tests/test_core.py` — Набор модульных тестов (`pytest`).
* `tools/pdf_to_md.py` — Утилита конвертации книг PDF в Markdown.
* `VSA_REFERENCE.md` — Структурированный референс по VSA/VPA (~35k токенов).
* `signals.sqlite` — База данных историй анализа, сигналов, исходов сделок и токенов.
* `requirements.txt` — Зафиксированные зависимости проекта (`requests`, `yfinance`, `pandas`, `numpy`, `streamlit`, `streamlit-autorefresh`, `pytest`, `plotly`, `MetaTrader5`).
* `.env.example` — Шаблон конфигурации ключей API.

## 🚀 Установка и запуск

1. Склонируйте репозиторий / откройте папку проекта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и впишите ваш API-ключ OpenRouter:
   ```env
   OPENROUTER_API_KEY=ваш_ключ_здесь
   MODEL=z-ai/glm-5.2
   ```
4. **Тестирование системы:**
   ```bash
   pytest tests/test_core.py
   ```
5. **Запуск веб-приложения:**
   ```bash
   streamlit run app.py
   ```
6. **Запуск фонового демона:**
   ```bash
   python bot.py
   ```
7. **Запуск симулятора Replay Mode:**
   ```bash
   python replay.py
   ```

## 🧠 Как работать с веб-интерфейсом

1. **Подключение счета:** В боковой панели нажмите **`🔗 Синхронизировать с MT5`** — бот подтянет ваш реальный баланс.
2. **Живой мониторинг:** Нажмите тумблер **`▶️ Включить живой 15м мониторинг сессии`** — страница будет автоматически обновляться каждые 60 секунд, и бот начнет вести торги с закрытием каждого 15-минутного бара без лишних кликов.
3. **График и Уровни:** Следите за Plotly-графиком: при появлении сигнала линии входа и стопа отобразятся прямо на графике.
4. **Учет результатов:** На вкладке **«📊 Журнал сделок & Winrate»** отмечайте результаты сделок (`Hit TP` / `Hit SL`) для отслеживания своей статистики.
